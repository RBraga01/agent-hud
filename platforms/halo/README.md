# Brilliant Labs Halo platform

The Halo adapter remains a separate private emulator-validated prototype. This
public directory contains status metadata only: no Lua runtime, SDK checkout,
vendor artefact, binary, cache, screenshot or copied private history.

Publishing/importing the adapter requires an explicit visibility decision and a
source, license, history, ignore and artefact review. Until then the shared M0
contract and its conformance evidence are the only cross-project boundary.
