# Halo emulator screenshots

Generated by the actual Halo Lua application inside halo-emulator 2.0.1 from
invented task `example-task`, revision 3. The profile B test uses single clicks,
an IMU tap and double clicks to reach a distinct confirmation screen. Only the
next double click sends a canonical decision. ERROR displays delivery uncertainty;
the retry confirmation reuses the same decision, and DUPLICATE/ACCEPTED shows SENT.
A separate newer-version scenario shows STALE and sends nothing.

The files in this directory are the reviewed evidence imported with the Halo
platform. New test runs write to the ignored `artifacts/` directory so a test
cannot silently replace the reviewed images.

Regenerate from `platforms/halo/` with
`python -m uv run pytest tests/test_m0_inputs.py -q`, then review the generated
files before deliberately replacing this set.

Captures: attention, request, menu, confirmation, sending, delivery-unknown,
retry-confirmation, accepted and stale. They are framebuffer evidence, not
physical-device validation. No SDK source/assets were copied into this folder.
